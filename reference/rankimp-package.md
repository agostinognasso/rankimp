# rankimp: Consensus Ranking of Variable Importance with Uncertainty

Variable importance rankings depend on the method, the random seed and
the resample used to compute them. This package treats every source of
importance as a judge expressing a ranking over the predictors, and
synthesises those rankings into a Kemeny median ranking with ties.
Uncertainty about the consensus is quantified through bootstrap rank
confidence sets, top-k probabilities and clustering of disagreeing
judges.
